# 가계부

쿠리만쥬·우사기 부부 가계부. 구글 시트를 DB로 쓰고, 안드로이드 앱이 결제 알림을 모아 기록한다.

## 구조

- `apps-script/Code.gs` — 구글 시트에 붙이는 API (조회·저장·과거 기록 이관)
- `src/` — 앱 (React + Vite, Capacitor로 APK 빌드)
- `android/` — 알림 수집 네이티브 플러그인 (`NotificationCapturePlugin`, `PaymentNotificationService`)

시트 탭

| 탭 | 내용 |
|---|---|
| `거래내역` | 거래 1건 = 1행. 앱이 읽고 쓰는 원본 |
| `카테고리` | 구분(지출/수입/저축)·이름·순서·통계제외. 여기서 고치면 앱에 반영 |
| `분류규칙` | 가맹점 키워드 → 카테고리 |
| `2025`, `2026` | 기존 양식. 손대지 않음 |

## 구글 시트 연결 (최초 1회)

1. 가계부 시트에서 **확장 프로그램 → Apps Script**를 연다.
2. `Code.gs` 내용을 전부 지우고 이 저장소의 `apps-script/Code.gs`를 붙여넣고 저장한다.
3. 위쪽 함수 선택에서 **`setup`**을 고르고 **실행**한다.
   - 권한 요청이 뜨면 본인 계정으로 승인한다. "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누른다. 본인이 만든 스크립트라 그렇다.
   - 시트에 `거래내역`, `카테고리`, `분류규칙` 탭이 생긴다.
   - **실행 로그**에 나오는 토큰을 복사해 둔다. 비밀번호처럼 다룬다.
4. (과거 기록을 옮기려면) 함수 **`migrateFromYearTabs`**를 실행한다. 여러 번 실행해도 중복되지 않는다.
5. 오른쪽 위 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (앱이 구글 로그인 없이 호출하기 때문. 토큰이 없으면 거부된다)
   - 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사한다.
6. 앱 **설정 → 구글 시트 동기화**에 URL과 토큰을 넣고 **저장하고 동기화**.

`Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영된다. URL은 그대로 유지된다.

## 개발

```bash
pnpm install
pnpm dev          # 브라우저 (알림 수집 제외 전부 동작)
pnpm test
pnpm android:apk  # android/app/build/outputs/apk/debug/app-debug.apk
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

## 알림 수집

설정 → 결제 알림 수집에서 알림 접근 권한을 허용하고, 카드사·은행 앱, 카카오톡, 메시지, 토스를 고른다.
고른 앱의 알림 중 금액(`…원`)이 들어간 것만 폰 안에 저장되고, 앱을 열 때 수집함으로 들어온다.
지금은 범용 파서라 수집함에서 확인 후 기록한다. 실제 알림 문구가 쌓이면 카드사별 파서를 추가해 자동 기록으로 바꾼다.
